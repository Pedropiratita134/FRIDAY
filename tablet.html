¿Por qué conviene una llave solo para la tablet?

El plan gratis de Groq tiene un tope por minuto y por día. Si la tablet usa la misma llave que la compu y el celu, se reparten el cupo. Hacé otra cuenta gratis en console.groq.com/keys con otro mail, creá una llave y pegala acá.

Luces, YouTube y Google Falta

Para esto la tablet usa un servicio tuyo y gratis en Cloudflare: guarda tus claves de Smart Life y de Google sin que queden a la vista. Se arma una vez, en unos 10 minutos.

Cómo armarlo, paso a paso
  1. Entrá a dash.cloudflare.com y creá una cuenta gratis.
  2. A la izquierda: Workers & Pages (puede estar dentro de Compute) → Create application → Start with Hello World! (o Create Worker). Ponele de nombre friday-casa y tocá Deploy.
  3. Tocá Edit code, borrá todo lo que hay y pegá este código: Después tocá Deploy.
  4. Volvé al Worker → Settings → Variables and Secrets → Add, y cargá estas (tipo Secret):
    FRIDAY_KEY
    TUYA_ID y TUYA_SECRET: el Access ID y el Access Secret de tu proyecto de Tuya (los mismos que pusiste en FRIDAY de la compu, en Ajustes → Casa).
    Tocá Deploy para guardar.
  5. Copiá la dirección del Worker (algo como https://friday-casa.tu-usuario.workers.dev) y pegala abajo.

Agenda y mails de Google Falta

La tablet te dice lo que tenés hoy, te avisa antes y te lee los mails nuevos.

Antes, una vez: el permiso en Google Cloud
  1. Entrá a console.cloud.google.com, en el mismo proyecto de FRIDAY.
  2. Create credentials → OAuth client ID → tipo Web application.
  3. En Authorized redirect URIs agregá: — y tocá Create.
  4. Copiá el Client ID y el Client secret (el secret Google lo muestra una sola vez) y cargalos en el Worker como GOOGLE_ID y GOOGLE_SECRET (Settings → Variables and Secrets), y tocá Deploy.
  5. Para que el permiso no se venza cada 7 días: Google Auth Platform → Audience → Publish app. Al conectar, Google va a decir "app no verificada": es la tuya, tocá Avanzado → Ir a FRIDAY.
